# FixMate – Smart Home Service Platform

FixMate is a full-stack web application that connects customers with technicians for home appliance repair and maintenance services.

## Live Website
https://fix-mate-client-pi13.vercel.app

## Features
- User registration and login
- Role-based access for customers, technicians, and administrators
- Browse available repair services
- Create and manage service bookings
- Technician dashboard for managing assigned bookings
- Admin dashboard for managing services and users
- Online payment integration with Stripe
- Responsive user interface

## Technologies
- Next.js
- React
- Tailwind CSS
- Better Auth
- Node.js and Express
- MongoDB
- Stripe

## Project Structure
- `client/` – Frontend application
- `server/` – Backend API

## Run Locally
```bash
npm install
npm run dev
```
Open http://localhost:3000
